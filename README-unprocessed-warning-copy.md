หัวข้อ: รูปที่ไม่ผ่านการประมวลจากระบบ ไม่สามารถดาวน์โหลดได้
คำอธิบาย: กรุณาเพิ่มรูป เลือกทรงผม ปรับแต่งเพื่อดาวน์โหลด

ข้อความนี้ใช้ในหน้าต่างแจ้งเตือนเดิมร่วมกันเมื่อพยายามบันทึกหรือดาวน์โหลดรูปที่ยังไม่ผ่านการประมวลผล ไม่ได้เปลี่ยนเงื่อนไขการบันทึก/ดาวน์โหลด สิทธิ์ เครดิต หรือการทำงานของปุ่ม

ไฟล์นี้ต่อจาก IDPROM-home-exit-actions-20261023.zip จึงคงปุ่มบันทึกและออก/ไม่บันทึกจากงานก่อนหน้าไว้แล้ว สามารถใช้ไฟล์ src/studio-editor.jsx ใน ZIP นี้แทนไฟล์จาก ZIP ก่อนหน้าได้เลย โปรเจ็กฐาน main ที่ตรวจล่าสุดคือ 97975dfbce3afe8534db42a3ad364538a0a32787

แตกไฟล์ทับจากรากโปรเจ็ก แล้ว build/deploy ตามขั้นตอนเดิม ไม่มีการเปลี่ยนฐานข้อมูลหรือการตั้งค่า npm run build ผ่าน 118 modules มีคำเตือนขนาด bundle เดิม ไฟล์นี้ยังไม่ได้ติดตั้งขึ้นเว็บไซต์
