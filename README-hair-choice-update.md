# ปรับตัวเลือกทรงผม — 23 ตุลาคม 2026

การเปลี่ยนรอบนี้มี 3 จุดใน 2 ไฟล์เท่านั้น:
- src/main.jsx: ไม่นำ seedream-35 (ทรงผมชายรายการแรกตามภาพ) มาแสดงในตัวเลือกชาย ทั้ง Studio และหน้าเดิม รายการชายเหลือ 7 แบบ ลำดับอื่นคงเดิม
- src/main.jsx: ชื่อปุ่มผมเดิมในหน้าเดิม → ไม่เลือกผม
- src/studio-editor.jsx: ชื่อปุ่มผมเดิมใน Studio → ไม่เลือกผม จุดร่วมนี้ครอบคลุมหญิงและชาย

การทำงานของปุ่มไม่เลือกผมคงเดิม เปลี่ยนเฉพาะชื่อ ไม่ลบผมหรือปรับวิธีประมวลผลเพิ่มเติม เก็บ catalog และไฟล์ภาพทรงเก่าเพื่อให้งานเดิมและ metadata ยังอ่านได้ ไม่ลบงานหรือแก้สิทธิ์/เครดิต

## ติดตั้ง

ZIP นี้รวมแพตช์รักษาเมคอัพเมื่อเปลี่ยนผมที่ส่งไปก่อนหน้าไว้ด้วย เพื่อให้ client/server เป็นรุ่นเดียวกัน ไม่ต้องติดตั้ง ZIP ก่อนหน้าซ้ำ:
- src/main.jsx รวมการแก้เมคอัพก่อนหน้าและการปรับตัวเลือกครั้งนี้
- src/studio-editor.jsx เปลี่ยนชื่อปุ่มตามคำขอครั้งนี้เท่านั้น
- production-portrait-pipeline.js, seedream-review-transport.js, job-store.js เป็นไฟล์จากแพตช์เมคอัพก่อนหน้าทุก byte ไม่มีการแก้เพิ่มในรอบนี้

ฐาน GitHub ล่าสุดที่ตรวจ: main 9997b616e51904c7b3a5a94263d394faed44c591
แตกไฟล์ทับจากรากโปรเจ็ก เก็บไฟล์อื่นไว้ แล้ว build/deploy ด้วยวิธีเดิม ต้องอัปเดตทั้ง client/server และโหลดหน้าใหม่หลังติดตั้ง ไม่มี migration ฐานข้อมูลหรือการเปลี่ยน key

ตรวจการเปลี่ยนเฉพาะ 3 จุดกับแพตช์ที่ส่งก่อนหน้าแล้ว ลำดับทรงอื่นและ catalog คงเดิม npm run build ผ่าน 118 modules มีเพียงคำเตือนขนาด bundle เดิม ZIP นี้ยังไม่ได้ deploy ขึ้นเว็บ การตรวจภาพจริงของเมคอัพก่อนหน้ายังมีข้อจำกัดตาม README ที่แนบ
