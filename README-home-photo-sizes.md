# ตัวอย่างขนาดรูปบนหน้าแรก

ฐานโปรเจ็กล่าสุด: niksupattra-ship-it/photo-ready-new main 6010a0562ffcdc682e536dc5f0ca4f6d2265efdf
วันที่: 23 ตุลาคม 2026

เพิ่มส่วน “ตัวอย่างขนาดรูป” บนหน้าแรก ใต้ตัวอย่างยอดนิยมและเหนือแถบคุณสมบัติ:
- ใช้รูปสมัครงานหญิง female-suit-03 ซึ่งเป็นรูปเดียวกับตัวอย่างเดิมของเว็บ จึงไม่มีการสร้างใบหน้าใหม่หรือเปลี่ยนแบบเสื้อ
- คอมพิวเตอร์แสดงภาพตัวอย่างด้านซ้ายและตัวเลือกด้านขวา มือถือเรียงเป็นคอลัมน์เดียว
- เลือกได้ 5 แบบ พร้อมดูสัดส่วน ขนาดมิลลิเมตร และขนาดไฟล์จาก Studio
- ปุ่ม “สร้างรูปสมัครงานของคุณ” เปิด Studio ด้วยชุดสมัครงานหญิงตัวอย่าง ผ่านขั้นตอนเลือกชุดเดิมของโปรเจ็ก
- ปรับข้อความขนาดเก่า 900 × 1200 px ในแถบคุณสมบัติที่อยู่ติดกัน ให้เป็น 2256 × 3072 px ตามไฟล์ปัจจุบัน

ขนาดที่แสดงตรงกับ Studio:
- ขนาดเดิม: 2256 × 3072 px
- 1 นิ้ว: 25 × 33 มม. / 590 × 780 px
- 1.5 นิ้ว: 30 × 40 มม. / 708 × 944 px
- 2 นิ้ว: 40 × 53 มม. / 944 × 1252 px
- 2.5 นิ้ว: 48 × 63 มม. / 1134 × 1488 px

ตัวอย่างหน้าแรกไม่เรียก AI ไม่หักเครดิต และไม่ดาวน์โหลดภาพ การประมวลผลและดาวน์โหลดงานจริงใช้สิทธิ์และขั้นตอนเดิม ไม่ได้แก้ exporter, PhotoSizeEditor, บัญชี หรือเครดิต

ภาพตัวอย่างนำมาจาก /assets/home-previews/job-uniforms--female-suit-03-example.webp ของเว็บเดิม และ fallback ไป /assets/job-uniforms/female-suit-03-example.png คนเดิม ภาพ preview เดิมมีขนาด 409 × 512 px ข้อมูล 2256 × 3072 px บนหน้าจอหมายถึงขนาดไฟล์ที่ระบบส่งออก ไม่ใช่ความละเอียดของภาพตัวอย่างนี้ ขนาดที่เห็นบนจอเป็นการเปรียบเทียบสัดส่วน ไม่ใช่มาตราส่วนพิมพ์จริง

## ติดตั้ง

แตกไฟล์ทับจากรากโปรเจ็ก โดยอัปเดตทั้ง 3 ไฟล์พร้อมกัน:
1. src/main.jsx
2. src/home-photo-sizes.jsx (ใหม่)
3. src/home-photo-sizes.css (ใหม่)

ไฟล์ภาพตัวอย่างมีอยู่ในโปรเจ็ก/เว็บไซต์แล้ว ไม่ต้องเพิ่มภาพใหม่ จากนั้น build/deploy ตามขั้นตอนเดิมและโหลดหน้าใหม่ ไม่มี migration ฐานข้อมูลหรือการตั้งค่า key

npm run build ผ่าน 120 modules มีคำเตือนขนาด bundle เดิม ตรวจ component จริงบน Chromium/WebKit ที่ 320/390/768/1024/1440px รวม 10 กรณีขนาดจอและ 50 กรณีเลือกขนาด ไม่มี overflow หรือ page error ตรวจ Enter/Space ปุ่มเริ่มสร้างรูป และการโหลดภาพตัวอย่างแล้ว ใช้ harness และ callback จำลอง ไม่ได้สร้างภาพ ชำระเงิน หรือเขียนบัญชีจริง และยังไม่ได้ deploy ขึ้นเว็บไซต์
