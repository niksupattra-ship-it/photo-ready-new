# Selected English hair length and nape boundaries

The English blond quiff (`seedream-77`) is a short tapered cut. An output with added hair hanging behind the ears toward the neck contradicts that selection. Existing prompts already prohibited such additions, but the AI reference for the imported men's set consisted of an isolated head/hair cutout without full neck context. Adding another general short-hair command alone would not supply the missing visual evidence.

English selected-hair requests now use one reference board in the existing Image 2 slot. The left panel retains the entire exact catalog hair guide, including intended long lengths. The right panel shows the corresponding exact picker photograph with the donor face blanked, so the selected ends and clear neck-side spaces remain visible. Its photo hash is checked before generation. The same generation receives a final reference-specific boundary rule after the generic ear-cleanup and placement rules. Short, bob, gathered and long cuts have distinct contracts: no invented extensions; no clipping authentic long hair or continuous bob ends. Donor neck, skin, ears, clothes and diagram markings have no output authority.

Thai reference bytes, the outfit layout, customer face geometry, provider call count and payment/credit paths are unchanged. English framing/cache provenance advances to v18 so explicitly generating the same selection does not reuse the old cached picture. Previously saved/generated pixels are not rewritten automatically.

`tests/english-selected-hair.test.js` checks all 33 English picker bindings, complete unchanged guide pixels inside the board, opaque reference backgrounds, blank donor faces, all four length contracts, the final production instruction and the existing single-call generation route. Targeted English male/female catalog and Natural/Makeup-pair tests also pass with the new reference board. The production build passes. These are reference/payload and mocked-provider tests; they do not demonstrate that a new live AI result for the customer's photo is free of invented strands.

The broader legacy suites are not wholly green: two male tests in `english-template-body.test.js` already reject their original skin-option fixtures with `original_portrait_ai_invalid`, reproduced against the original pipeline, and an older male-source-manifest assertion expects metadata absent from the imported 66–78 set. Those unrelated fixtures are not treated as validation of this change.
