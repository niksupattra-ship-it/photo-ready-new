# Complete Thai neck backing

Current Thai female V5 clients submit `thaiNeckBackingVersion=thai-complete-neck-backing-v1`. English requests and older open clients retain their existing processing and framing.

Two conflicting constraints could leave only an upper-neck stump: a close-cropped source frame had no space for the requested deep skin backing, while the final neck-side reference was a separate rectangle ending above the full U base. Merely asking for a deeper base did not create canvas space. The initial preparation still receives the untouched original upload; the final generation now receives the prepared photo on a larger temporary blue canvas when the measured face bounds need more room. Existing image pixels remain unchanged, with uniform downsampling only for the server's bounded working size. The requested output keeps the expanded aspect at normal 2K area so the new space is not cropped off again.

The final request uses the original full `wide-deep-u-v1.png` as one continuous guide. Its neck, both clavicles and broad rounded lower U are all required output, including hidden overlap beneath a separate deep/wide collar. The competing neck-only rectangle and its split-guide instructions are absent from this path. Neck pixels are generated by the existing AI request; no stretched skin bridge or additional provider edit is added.

Face bounds for an unselected/default hairstyle are optional. Missing bounds use conservative padding; inability to prepare the added canvas falls back to the existing valid image. There is no new ratio/coverage rejection, additional generation, credit reservation, retry or automatic reprocessing of saved photos. Natural and Makeup retain the existing paired processing. Existing source ownership, cancellation, completion and provider-failure behavior remains in force. Thai cache keys include this separate version; English cache keys and its full-body output are unchanged.
