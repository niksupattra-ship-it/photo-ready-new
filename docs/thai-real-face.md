# Original face and eyes in new Thai portraits

New Thai full-outfit submissions opt into `thai-real-face-original-eyes-v1`, included in both result and submission keys. Historical requests and English prompt bytes remain unchanged.

The released shared Makeup policy requested symmetrical brows, lifted/curled fuller lashes and a polished beauty finish. New Thai requests remove those conflicting clauses and append a final original-face authority after all outfit, cosmetics and proportion instructions. Preserve original iris/pupil colour, size, gaze, catchlights, eyelid anatomy, eye expression, original brow/lash patterns and natural asymmetry. Preserve actual cheek/jaw/chin/face proportions with no slimming, independent-axis scale or feature movement. Gentle skin-colour/temporary-blemish correction and restrained pink-nude lip/cheek pigment remain conditional on selecting Makeup; real pores, shading and age-defining anatomy remain.

Generation still starts from the original upload, uses the same original provider request and existing geometry/delivery path. No face paste, local warp, extra AI call, image mask, automatic paid regeneration, price or entitlement change is introduced. Previously completed images retain their original pixels.

Tests check released Makeup text against the new transformation, English/archived byte preservation, Natural behaviour, client payload/cache versions and the production male/female request path with an inert provider. They verify original call counts and identical delivered stub pixels, not live AI fidelity. A generative model cannot provide a pixel-identity guarantee from prompt tests alone.
