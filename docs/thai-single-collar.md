# Thai full-body collar integrity

A flat screenshot cannot distinguish an AI-painted duplicate collar from an obsolete compositing layer. Inspection found two gaps: current v12 Thai generation did not receive the historical single-collar rule (the older rule was gated to a different version), and Studio hydration did not reject head-only neck bridges attached to a complete AI body or dangling from a replaced head.

New Thai requests opt into `thai-single-collar-v1`. This is a final clothing-authority instruction in the original provider request: original/hair/makeup photos supply identity/hair/finish, and only the selected outfit supplies the inner collar, tie and outer lapels. Legitimate inner-shirt and jacket layers remain intact. Both client result and submission keys include the optional revision. Historical requests without the marker retain their prompt; English never opts in. There is no second provider request, paid regeneration, mask, image repaint, price or credit change.

Thai hydration removes obsolete `neck-fit` layers associated with a complete visible AI portrait and orphan bridges left after head replacement. Unrelated head-only bridges, intentionally placed native suits, insignia, original generated pixels and project history are preserved. The existing full-body route continues to hide its placeholder suit. This repair runs when restoring a project and when accepting first/hair results, so preview and export share the same valid layers.

An extra collar already painted inside an existing flattened AI output cannot be repaired by hiding a layer; new generation receives the corrected policy. This change does not automatically charge or regenerate that output, nor claim a live provider result was visually verified.

Tests exercise current/historical male/female production requests with an inert provider, one call per generation, identical returned pixel bytes, cache/payload opt-in and mixed head-only/full-body project layers. A real browser compositor fixture restores a visible obsolete neck patch on desktop/mobile and proves the patch is removed without losing the complete portrait or invoking AI/payment.
