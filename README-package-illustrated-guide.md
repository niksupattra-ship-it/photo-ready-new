# ปรับส่วนคำอธิบายแพ็กเกจตามภาพอ้างอิง

ฐานโปรเจ็ก: niksupattra-ship-it/photo-ready-new main 9769ab8b53317e9a7c31b1a01916365bf1770bc2
วันที่: 23 ตุลาคม 2026

แก้เฉพาะส่วนคำอธิบายใต้การ์ดราคา:
- การใช้เครดิต: การ์ดสีฟ้า ภาพรูปถ่ายซ้อนและเพชร เน้น ใช้ 1 เครดิต พร้อมกล่องอธิบายสีฟ้า
- การเก็บงาน: การ์ดสีชมพู ภาพโฟลเดอร์และอัปโหลด พร้อมกล่องคำเตือนสีชมพู
- ทดลองใช้ฟรี: แถบสีเขียวเต็มความกว้าง พร้อมของขวัญ นาฬิกา และเงื่อนไขเครดิตทดลองเดิม
- ส่วนท้ายมีเงื่อนไขทางซ้ายและ PromptPay ทางขวา มือถือเรียงลงให้อ่านง่าย

ภาพรูปถ่ายซ้อนใช้รูปผู้หญิงตัวอย่างเดิมของเว็บ /assets/home-previews/job-uniforms--female-suit-03-example.webp ไม่ได้สร้างหรือแก้ใบหน้าใหม่ ภาพประกอบที่เหลือเป็น CSS/SVG แบบตกแต่ง ข้อความเป็น HTML จริง อ่านและจัดบรรทัดตามจอได้ SVG ใช้ ID แยกแต่ละ instance

ราคา จำนวนเครดิต สิทธิ์ ปุ่มเลือกแพ็กเกจ คำสั่ง startCheckout และเงื่อนไขธุรกิจคงเดิม บล็อกราคา/สิทธิ์/checkout ตรวจเทียบกับฐานแล้วเหมือนเดิมทุกอักษร ไม่ได้แก้บัญชี เครดิต API ชำระเงิน หรือขนาดหน้าต่างแพ็กเกจ

## ติดตั้ง

แตก ZIP ทับจากรากโปรเจ็ก อัปเดต 3 ไฟล์พร้อมกัน:
1. src/package-offers.jsx
2. src/package-guide-art.jsx (ใหม่)
3. src/package-guidance.css (ใหม่)

รูปตัวอย่างมีอยู่บนเว็บ/โปรเจ็กเดิมแล้ว ไม่ต้องเพิ่มภาพใหม่ จากนั้น build/deploy ตามวิธีปกติของโปรเจ็กและโหลดหน้าใหม่ ไม่มีการเปลี่ยนฐานข้อมูลหรือการตั้งค่า key

npm run build ผ่าน 122 modules มีคำเตือนขนาด bundle เดิม รายงานการแสดงผลและปุ่มอยู่ใน VERIFY-package-illustrated-guide.json ทดสอบ component จริงกับ callback จำลอง ไม่ได้สร้างรายการชำระเงินหรือเขียนบัญชีจริง และยังไม่ได้ deploy ขึ้นเว็บไซต์
