## สาเหตุที่พบ

ข้อความ “AI ยังตัดเสื้อเดิมออกไม่ครบ” มาจากตัวตรวจผลในฝั่งเว็บ หลังได้รับภาพจาก AI แล้ว โค้ดเดิมเรียกตัวตรวจนี้ก่อนฟังก์ชันลบเสื้อเดิม และเรียกฟังก์ชันลบเสื้อเฉพาะตอนเปลี่ยนรูปต้นฉบับ ทำให้ผลที่ยังมีเสื้อเหลือถูกปฏิเสธก่อนถึงขั้นตอนทำความสะอาด การประมวลผลครั้งแรกและการเปลี่ยนทรงผมจึงไม่ได้ใช้ขั้นตอนลบเสื้อนี้ด้วย

## การแก้เฉพาะจุด

- เรียกฟังก์ชันลบเสื้อเดิมที่มีอยู่แล้วในจุดกลาง ก่อนตรวจผล สำหรับการประมวลผลครั้งแรก การเปลี่ยนรูป และการเปลี่ยนทรงผม
- เปลี่ยนเฉพาะความโปร่งใสของพิกเซลใต้คางที่มาสก์ระบุเป็นเสื้อ และไม่ทับคลาสผิวหรือผม คงขนาดภาพและสีเดิม ไม่ขยายมาสก์ ไม่ปรับแต่งใบหน้าเพิ่ม
- เก็บ metadata `idprom*` ของงานไว้ครบ และใช้มาสก์ชุดเดิมตรวจผลหลังทำความสะอาด เก็บผลที่ทำความสะอาดแล้วในแคช
- คงตัวตรวจเสื้อ สัดส่วน และทรงผมเดิม หากตรวจไม่ได้หรือยังไม่ผ่าน จะไม่ยอมรับผล ไม่ปิดตัวตรวจหรือผ่อนเกณฑ์
- กันงานที่ยกเลิกหรืองานที่ถูกแทนที่ส่งผลย้อนกลับ และตัดการลบเสื้อซ้ำในเส้นทางเปลี่ยนรูป

ไม่มีการเพิ่มคำขอ AI หรือโมเดลเสียเงิน ไม่มีการแก้ server, ฐานข้อมูล, บัญชี, ราคา, เงื่อนไขสิทธิ์ หรือวิธีเพิ่ม/หัก/คืนเครดิต

## วิธีอัปเดต

ชุดนี้เป็นไฟล์แก้เฉพาะส่วน ไม่ใช่โปรเจ็กต์ทั้งหมด แทนที่ runtime **ไฟล์เดียว** `src/main.jsx` ในโปรเจ็กต์ฐานข้างต้น แล้ว build/deploy ตามขั้นตอนเดิม จากนั้นเปิดหน้าเว็บใหม่ให้โหลด bundle ใหม่ ไม่ต้องล้างข้อมูลบัญชี งาน หรือฐานข้อมูล

`scripts/check-portrait-clothing-completion.mjs` เป็นชุดทดสอบใหม่ เอกสาร README/VERIFY ไม่ใช่ runtime

## ผลตรวจ

- `npm run build` ผ่าน 117 modules; มีคำเตือนขนาด bundle เดิม
- ชุดตรวจใหม่ 15 กรณี: ลำดับ cleanup/validation, ผิว/หู/คอ/ผม, metadata, แคช, ยกเลิก/เปลี่ยนงาน, และคงการปฏิเสธผลที่ยังผิด
- MediaPipe และ Canvas PNG จริงบน Chromium และ WebKit: ภาพตัวอย่างในโปรเจ็กต์ 3 ภาพต่อเอนจิน ผ่านตัวตรวจหลังลบเสื้อ พิกเซลที่จัดเป็นผิว/ผมและพิกเซลเหนือคางคงเดิม สีของพิกเซลทึบแสงที่ยังอยู่คงเดิม
- ชุดตรวจเดิม: เริ่มประมวลผล/เครดิต 12 กรณี, ล็อกอิน/กระเป๋า 18, หน้าดูเครดิต 7, สิทธิ์ Studio และตำแหน่งชุด ผ่าน
- เทียบไฟล์กับฐาน พบ runtime เปลี่ยนเฉพาะ `src/main.jsx`; alpha helper และ completion guard เดิมไม่เปลี่ยน

รันชุดตรวจเฉพาะจุดได้ด้วย `node scripts/check-portrait-clothing-completion.mjs`

ยังไม่ได้ deploy ขึ้นเว็บจริง ไม่ได้ใช้บัญชีลูกค้าหรือเรียก AI เสียเงิน ผลทดสอบยืนยันข้อผิดพลาดด้านลำดับและขอบเขตการแก้ในภาพที่ทดสอบ ไม่ใช่การรับรองว่าโมเดลจะแยกเสื้อ/ผิว/ผมถูกต้องกับภาพทุกแบบ การทดสอบ WebKit เป็นเอนจินบนเครื่องทดสอบ ไม่ใช่อุปกรณ์ iOS จริง
