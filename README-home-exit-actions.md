# ปุ่มกลับหน้าหลักใน Studio

ฐานโปรเจ็ก: niksupattra-ship-it/photo-ready-new main 97975dfbce3afe8534db42a3ad364538a0a32787
วันที่: 23 ตุลาคม 2026

แก้เฉพาะ src/studio-editor.jsx ในส่วนปุ่มของหน้าต่างยืนยันกลับหน้าหลัก:
- บันทึกและออก: รอขั้นตอนบันทึกเดิมให้สำเร็จก่อนกลับหน้าหลัก หากบันทึกไม่สำเร็จยังอยู่ใน Studio พร้อมข้อความเดิม ไม่ต้องกดยืนยันออกอีกครั้งหลังบันทึกสำเร็จ
- ไม่บันทึก: ปิดหน้าต่างแล้วกลับหน้าหลักทันทีผ่าน callback เดิม ไม่เรียกบันทึกงาน
- Escape/การยกเลิกหน้าต่างยังกลับไปแก้ไขต่อได้

ปุ่มนี้ใช้ร่วมกันทั้งมือถือ แท็บเล็ต และคอมพิวเตอร์ ไม่ได้แก้การตรวจสิทธิ์ การคิดเครดิต API บันทึกงาน หรือระบบอื่น บัญชีและงานที่เคยบันทึกไม่ได้ถูกลบ การเก็บ draft ชั่วคราวในหน่วยความจำของหน้าหลักยังเป็นพฤติกรรมเดิม

แตก ZIP ทับจากรากโปรเจ็ก ให้ src/studio-editor.jsx แทนไฟล์เดิม แล้ว build/deploy ตามขั้นตอนปกติของโปรเจ็ก โหลดหน้าใหม่หลังติดตั้ง ไม่มีการเปลี่ยนฐานข้อมูลหรือค่าการตั้งค่า

npm run build ผ่าน 118 modules มีคำเตือนขนาด bundle เดิม รายละเอียดตรวจอยู่ใน VERIFY-home-exit-actions.json ชุดตรวจเบราว์เซอร์เป็นการใช้ปุ่ม/dialog จากซอร์สจริงใน harness โดยจำลองผลของการบันทึก ไม่ได้เขียนงานลงบัญชีจริงหรือ deploy ขึ้นเว็บ
