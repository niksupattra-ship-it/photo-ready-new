ตั้งค่าลืมรหัสผ่าน IDพร้อม

1. สมัคร Resend ที่ https://resend.com/signup
2. Domains > Add domain ใช้ mail.idpromth.com
3. เพิ่ม DNS ตามรายการที่ Resend แสดง ในผู้ให้บริการ DNS ของ idpromth.com แล้วกด Verify รอให้ Verified
4. API Keys > Create API Key ใช้สิทธิ์ Sending access สำหรับโดเมนนี้
5. Railway > บริการเว็บ > Variables เพิ่ม:
   RESEND_API_KEY = คีย์จาก Resend
   PASSWORD_RESET_FROM = IDพร้อม <no-reply@mail.idpromth.com>
   APP_URL = https://idpromth.com
6. แทนไฟล์ทั้ง 6 ไฟล์ตามเส้นทางใน ZIP แล้ว Deploy
7. ทดลองด้วยบัญชีของคุณ: เข้าสู่ระบบ > ลืมรหัสผ่าน > ส่งลิงก์ > ตรวจอีเมล/จดหมายขยะ > ตั้งรหัสใหม่ > เข้าสู่ระบบ แล้วตรวจเครดิตและงานเดิม

ลิงก์ใช้ครั้งเดียว หมดอายุใน 30 นาที รหัสต้องมี 8–128 ตัวอักษร หลังเปลี่ยนรหัส ระบบยกเลิก session เดิมให้เข้าสู่ระบบใหม่ ไม่แก้ wallet หรือ saved works
ไม่ต้องสร้างกล่องจดหมายของ no-reply เพื่อส่งผ่าน Resend แต่โดเมนต้องยืนยันแล้ว เก็บ API Key ใน Railway เท่านั้น ไม่ใส่ในโค้ดหน้าเว็บหรือส่งคีย์ในแชต
ยังไม่ได้ส่งอีเมลจริง ต้องตั้งค่าข้างต้นก่อน
