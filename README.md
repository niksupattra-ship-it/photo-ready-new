# Photo ID Studio TH

เวอร์ชันสร้างใหม่จากสถานะล่าสุดของโปรเจกต์ "รูปพร้อมใช้"

## สิ่งที่มีในเวอร์ชันนี้

- อัปโหลดรูปใบหน้า JPG / PNG / WEBP
- พรีวิวระยะภาพแนวตั้ง 2:3
- ตั้งระยะเป็นแบบเห็นศีรษะ + หัวไหล่ ไม่ซูมหน้าแน่น
- ชุดเริ่มต้น: **สูทหญิงสุภาพ**
- ทรงผม 1–20 โดย **ค่าเริ่มต้น = ทรง 20**
- พื้นหลัง ขาว / ฟ้า / เทาอ่อน
- Responsive ใช้ได้ทั้งมือถือและคอมพิวเตอร์
- Backend `/api/generate` เตรียมสำหรับ OpenAI Images Edit API
- ถ้ายังไม่มี API key เว็บยังเปิดและทดสอบหน้าจอ/ระยะภาพได้โดยไม่เสียเครดิต
- Prompt เน้นรักษาใบหน้าเดิม, ปรับเฉพาะทรงผม/ชุด/คอ, และจัดเฟรมตามแบบล่าสุด

## เปิดบนเครื่อง

ต้องมี Node.js 20+ (แนะนำ 22+)

```bash
npm install
npm start
```

จากนั้นเปิด

```text
http://localhost:3000
```

## เปิด AI ภายหลัง

1. คัดลอก `.env.example` เป็น `.env`
2. ใส่คีย์ใน

```env
OPENAI_API_KEY=...
```

3. ปิดและเปิดเซิร์ฟเวอร์ใหม่

> ห้ามใส่ API key ลงใน `public/app.js` หรือไฟล์หน้าเว็บ เพราะผู้ใช้เว็บสามารถเห็นได้

## โมเดล

ค่าเริ่มต้นในโปรเจกต์นี้:

```env
IMAGE_MODEL=gpt-image-1
```

เลือกไว้เพราะโค้ดใช้ `input_fidelity=high` เพื่อพยายามรักษาใบหน้าเดิมในการแก้ภาพ

## หมายเหตุสำคัญ

- ทรงผมในหน้าจอเป็นตัวเลือก/หมายเลขสำหรับส่งคำสั่งไป AI ยังไม่ใช่ภาพ reference hairstyle จริง
- ถ้าต้องการให้ทรง 1–20 ตรงกับแบบต้นฉบับ 100% ขั้นต่อไปควรใส่ไฟล์ reference ของแต่ละทรง และส่ง reference นั้นเข้ากระบวนการแก้ภาพด้วย
- เวอร์ชันนี้ยังไม่มีระบบสมาชิก/เครดิต/ชำระเงิน เพราะตั้งใจสร้างแกนหลักของหน้าทำรูปให้กลับมาใช้งานก่อน
