# จัดข้อความใต้แพ็กเกจให้อ่านง่าย

ฐานโปรเจ็ก: niksupattra-ship-it/photo-ready-new main 8d113bf9aa4eb5d40385c29c4e027271a50454b8
วันที่: 23 ตุลาคม 2026

แก้เฉพาะ src/package-offers.jsx ในส่วนจัดวางข้อความใต้การ์ดแพ็กเกจ:
- แบ่งการใช้เครดิตและการเก็บงานเป็นสองกลุ่ม มีหัวข้อย่อยและเส้นคั่น
- จอกว้างแสดงกลุ่มคำอธิบายสองคอลัมน์ มือถือเรียงลงเป็นคอลัมน์เดียว
- ข้อความอธิบายชิดซ้าย แยกน้ำหนักข้อความหลัก/รอง พร้อมระยะห่างที่อ่านง่าย
- แยกบรรทัดทดลองใช้ฟรีออกจากคำอธิบายหลัก
- รวมลิงก์เงื่อนไขและ PromptPay เป็นแถวท้าย บนมือถือเรียงลง

ข้อความเงื่อนไขเดิมยังอยู่ครบ เพิ่มเพียงหัวข้อย่อยช่วยแยกกลุ่ม ราคา จำนวนเครดิต รายการสิทธิ์ ปุ่มซื้อแพ็กเกจ และคำสั่ง startCheckout เหมือนเดิมทุกอักษร ไม่ได้เปลี่ยนเงื่อนไขธุรกิจหรือวิธีชำระเงิน CSS ใหม่จำกัดขอบเขตในหน้าต่างแพ็กเกจ ไม่แก้หน้าเงื่อนไขหรือ QR ชำระเงิน

แตก ZIP ทับจากรากโปรเจ็ก ให้ src/package-offers.jsx แทนไฟล์เดิม แล้ว build/deploy ตามขั้นตอนปกติ ไม่มีการเปลี่ยนฐานข้อมูลหรือค่าการตั้งค่า งานก่อนหน้าเรื่องเมคอัพ ทรงผม ปุ่มกลับหน้าหลัก และข้อความเตือนรูปไม่ผ่านการประมวลผลยังคงเดิม

npm run build ผ่าน 118 modules มีคำเตือนขนาด bundle เดิม รายละเอียดตรวจการแสดงผลและปุ่มอยู่ใน VERIFY-package-notes-layout.json การทดสอบใช้ component จริงพร้อม callback จำลอง ไม่ได้สร้างรายการชำระเงินจริง ไฟล์นี้ยังไม่ได้ติดตั้งขึ้นเว็บไซต์
