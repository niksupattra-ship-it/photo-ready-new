# IDพร้อม — เพิ่มรูปใหม่ครั้งที่สองแล้วทรงผมผิดแบบ

ฐานโค้ดล่าสุด: `niksupattra-ship-it/photo-ready-new` commit `97e8854f553304d7a035f34393c385c2c8cccb9c` ตรวจซ้ำก่อนจัดชุดแล้วว่าเป็น HEAD ปัจจุบัน ชุดป็อปอัพสำเร็จ ข้อความแพ็กเกจ และการแก้เสื้อเดิมก่อนหน้านี้อยู่ในฐานนี้ครบ

## สิ่งที่ตรวจพบ

จำลองเส้นทางจริง เพิ่มรูป A → ประมวลผล → เพิ่มรูป B → เลือกทรงผม พบว่า client ส่งไฟล์ B และรหัสที่เลือกถูกต้อง งานและแคชแยกตาม bytes ของรูป/รหัสทรงผม/บัญชี จึงไม่มีหลักฐานให้สรุปว่าเกิดจากรูป A ค้างในแคช

ข้อบกพร่องที่ยืนยันได้คือ ระบบกำหนด `hairId` ที่ขอให้เลเยอร์ผลลัพธ์เอง แล้วตรวจว่าโค้ดรหัสตรงกัน และตรวจว่าผมเปลี่ยนจากต้นฉบับหรือไม่ แต่ยังไม่ได้เทียบหน้าม้าและความยาวกับแบบที่ผู้ใช้เลือก ผล AI ที่เปลี่ยนเป็นทรงอื่นจึงอาจผ่าน ส่วนตัวตรวจใบหน้าเดิมเป็นการตรวจสัดส่วน ไม่ใช่การยืนยันบุคคล

แบบที่เลือกในภาพตรงกับทรง 19 แสกกลาง เปิดหน้าผาก ปลายระดับไหล่ ไฟล์อ้างอิงปัจจุบันตรงกับภาพตัวอย่าง ผลที่มีหน้าม้าจึงขัดกับแบบที่เลือก แต่ไม่มีต้นฉบับ B หรือผล AI ดิบของงานนั้นให้ตรวจเทียบใบหน้าโดยตรง

## การแก้

1. เฉพาะรูปที่เพิ่มแทนรูปซึ่งเคยประมวลผลแล้ว และเลือกทรงจาก catalog: วัดกรอบใบหน้าจากไฟล์ใหม่ที่ส่งจริง เพิ่มพิกัดกรอบในงานนั้น ฝั่ง server ครอปจาก bytes ของงานเดียวกันเท่านั้น ส่งเป็นภาพยึดรายละเอียดบุคคลท้ายคำขอ AI เดิม ภาพคนยังเป็น Image 1 และทรงผมยังเป็น Image 2 ไม่ใช้รูป A ผลเก่า หรือหน้าในภาพตัวอย่างเป็นแหล่งภาพยืนยัน
2. ภาพยึดใบหน้าจำกัดด้านยาวไม่เกิน 1024 px รักษาสัดส่วน รองรับ EXIF ไม่เปลี่ยนขนาดต้นฉบับหรือ master และใช้ Sharp pipeline เดียว ไม่มีภาพเต็มเฟรม PNG ชั่วคราวเพิ่ม
3. เพิ่มการเทียบโครงสร้างผมกับภาพตัวอย่างของทรงที่เลือก โดยใช้ FaceLandmarker/ImageSegmenter เดิมในเครื่อง ไม่เพิ่มโมเดลเสียเงิน ตรวจเฉพาะความขัดแย้งที่ชัด เช่น แบบเปิดหน้าผากแต่ได้หน้าม้า หรือความยาวต่างมากเมื่อเห็นปลายผมครบและไม่ติดขอบภาพ
4. ปรับบริเวณวัดหน้าม้าตามขนาดหน้าผากของแต่ละคน ไม่ใช้สีผิว/สีผมตัดสิน หากหลักฐานไม่พอหรือโหลดตัวอย่างไม่ได้ จะไม่เดาความผิดและยังใช้ตัวตรวจเดิม ไม่ปิดกั้นทุกภาพด้วยเกณฑ์ใหม่
5. เพิ่มคำสั่งเฉพาะทรง 19 ว่าเปิดหน้าผากและไม่มีหน้าม้า แยก cache policy ของผลที่มีภาพยึดใบหน้าจากผลเดิม เพื่อไม่เรียกผลก่อนแก้กลับมาใช้

การตรวจทำก่อนยืนยันส่งมอบงาน ผลที่ผิดชัดเจนจะไม่ถูกประกาศสำเร็จและไม่เก็บไว้ในแคช ใช้ขั้นตอนยกเลิก/คืน reservation เดิม ไม่มีการสร้างซ้ำอัตโนมัติ ไม่มีการเพิ่มรอบ AI หรือโมเดลใหม่ ภาพใบหน้าครอปเป็นข้อมูลประกอบในคำขอ 2K เดิมหนึ่งครั้ง ไม่ใช่การสร้างภาพเพิ่ม

ระบบบัญชี สิทธิ์ ทดลอง ชำระเงิน เพิ่ม/หัก/คืนเครดิต การบันทึก เลเยอร์ชุด พื้นหลัง และเครื่องประดับไม่เปลี่ยน ไม่มีการนำผิวหรือเครื่องสำอางจากต้นฉบับกลับมาทับผลแต่งหน้า

## วิธีอัปเดต

แทนที่ runtime 5 ไฟล์พร้อมกันตามตำแหน่งเดิม:

- `src/main.jsx`
- `src/selected-hair-check.js` — ไฟล์ใหม่
- `hairstyle-catalog.js`
- `production-portrait-pipeline.js` — ไฟล์ที่รากโปรเจ็กต์
- `seedream-review-transport.js` — ไฟล์ที่รากโปรเจ็กต์

จากนั้น build และ deploy/restart server ตามขั้นตอนเดิม เปิดหน้าเว็บใหม่เพื่อรับ bundle ใหม่ ไม่ต้องแก้ฐานข้อมูล รีเซ็ตบัญชี หรือเปลี่ยน API key

ไฟล์ `src/production-portrait-pipeline.js` เป็นอีกสำเนาที่ server ปัจจุบันไม่ได้ import ไม่ใช่ไฟล์ที่ต้องแทนที่ในชุดนี้

## ผลตรวจ

- Build ผ่าน 118 modules ด้วย dependencies ตาม lock เดิม; มีคำเตือนขนาด bundle เดิม
- เส้นทางรูปที่สอง/รหัส/พิกัด/แคช/ยืนยันผล 12 กรณี รวมการเพิ่มรูปและ commit จริงด้วย transport จำลอง ชุด พื้นหลัง เครื่องประดับคงเดิม
- ภาพยึดบุคคล 10 กรณี ใช้ Sharp จริง รวม EXIF 8 แบบ ภาพโทรศัพท์ขนาดใหญ่ การสลับ A/B และคำขอเดิมที่ไม่มี field
- ตัวตรวจโครงสร้างผม 15 กรณี รวมหน้าผากสั้น แสง ขนาด ตำแหน่ง ปลายผมติดขอบ และมาสก์ไม่ครบ
- MediaPipe จริงทั้ง Chromium และ WebKit: ต่อเอนจินทดลอง 42 ภาพ วัดได้ 40 ภาพ (ภาพตัวอย่าง catalog 35 + ตัวอย่างเปลี่ยนแสง/ขนาด/หน้าผาก/คน 5); PNG แบบผมล้วน 2 ภาพไม่มีใบหน้าตามคาด ทุกแบบเทียบตัวเองผ่าน กรณีเลือก 19 แต่ได้หน้าม้าแบบ 21 ถูกตรวจพบ ตัวอย่างเปิดหน้าผากและตัวอย่างปรับเปลี่ยน 5 กรณีไม่ถูกปฏิเสธผิด
- ชุดเดิม: คำสั่งทรงผม 35 แบบและ production path จำลอง, ลบเสื้อ 15, เริ่มประมวลผล/เครดิต 12, เครดิตในป็อปอัพ 9, สิทธิ์ Studio และตำแหน่งชุด ผ่าน

รันชุดตรวจใหม่ได้ด้วย:

```sh
node scripts/check-second-upload-contract.mjs
node scripts/check-selected-hair-check.mjs
node scripts/check-portrait-identity-anchor.mjs
```

## ขอบเขตผลทดสอบ

ยังไม่ได้ deploy หรือเรียก AI จริง ไม่มีการใช้บัญชีลูกค้าหรือเขียนข้อมูลการเงิน ภาพยึดบุคคลเป็นการเสริมข้อมูลให้โมเดล ไม่ใช่การรับรองว่าใบหน้าจะตรงต้นฉบับทุกภาพ ตัวตรวจผมตรวจความต่างเชิงโครงสร้างบางประเภท ไม่ใช่ตัวจำแนกรหัสทรงผมทั้งหมดหรือระบบจดจำใบหน้า ไม่รับรองว่าทุกรูปจะผ่านหรือจะได้ผลถูกต้องครั้งแรก ต้องตรวจผลจาก AI จริงหลัง deploy เพิ่มเติม
