กดดาวน์โหลดครั้งแรกเปิดหน้าปรับขนาดเดิม พร้อมลายน้ำหากยังไม่ปลดล็อก
กดดาวน์โหลดในหน้าปรับขนาดจึงตรวจสิทธิ์ ถ้ายังไม่ปลดล็อก ปิดหน้าปรับขนาดแล้วเปิดหน้าโปรเดิม
ผู้ที่ปลดล็อกแล้วดาวน์โหลดต่อได้ตามเดิม ไม่เปลี่ยนราคา เครดิต รายการผม หรือส่วนอื่น
การดาวน์โหลดอัตโนมัติหลังปลดล็อกยังตรวจสิทธิ์เช่นเดิม
หลังแทนไฟล์ให้ npm run build และ deploy client ตามขั้นตอนเดิม
ผ่าน production build และ Chromium desktop/mobile emulation 16 กรณี รวมลำดับ crop ก่อน paywall, ลายน้ำ, ดาวน์โหลดหลังจ่าย, ดาวน์โหลดซ้ำและ crop จริง
ไม่ได้แก้เว็บจริงหรือทดสอบตัดเงินจริงในรอบนี้
