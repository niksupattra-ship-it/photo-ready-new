พฤติกรรม
- สร้างและเปลี่ยนผมฟรีไม่จำกัดจำนวนครั้งต่อวัน มีลายน้ำจนกว่างานจะปลดล็อก รับคำขอสร้างครั้งละหนึ่งงานต่อบัญชี/กระเป๋าเพื่อไม่ให้ส่งงานซ้อน
- แสดงทรง AI หญิง 5 ทรง ชาย 5 ทรง รวม 10 ทรง นอกเหนือจากตัวเลือกไม่เลือกทรงผม
- ยอดเดิม generation_remaining + hair_remaining ยังคงค่าเดิม ไม่ย้ายหรือล้างยอด แต่ใช้เป็นสิทธิ์ปลดล็อกดาวน์โหลด 1 สิทธิ์ต่อ 1 งาน
- งานหมายถึงการอัปโหลดต้นฉบับหนึ่งครั้ง ทรงผมหลายทรงของต้นฉบับครั้งนั้นอยู่ในสิทธิ์เดียวกัน เพิ่มต้นฉบับใหม่เป็นงานใหม่ รวมถึงอัปไฟล์เดิมอีกครั้งเป็นงานใหม่
- ปลดล็อกซ้ำ/ดาวน์โหลดหลายขนาด ไม่หักสิทธิ์ซ้ำ หากสิทธิ์หมดให้ชำระเพื่อปลดล็อกงานใหม่
- งานบันทึกเดิมที่มีอยู่ตอนเปิดใช้นโยบายใหม่ถูกทำทะเบียนข้อยกเว้นครั้งเดียว เฉพาะเจ้าของที่เปิดงานนั้นจากรายการบันทึกเดิม การเปลี่ยนผมในงานเดิมต้องยืนยันต้นฉบับเดิมตรงกันจึงยังใช้ข้อยกเว้นได้
- ไม่เปลี่ยนอายุเก็บงานเดิม 45 วัน หรือขีดจำกัด 3 งานของระบบเดิม คำว่าไม่จำกัดหมายถึงจำนวนดาวน์โหลดของงานที่ยังเปิดได้ ไม่ใช่เพิ่มระยะจัดเก็บ
- ลูกค้าเดิมยังบันทึกงานที่มีสิทธิ์ได้ งานใหม่ที่บันทึกภายหลังไม่กลายเป็นงานข้อยกเว้นเก่า
- บัญชีใหม่ไม่มีปุ่มบันทึกงาน และ API ปฏิเสธการบันทึก แม้ชำระค่าดาวน์โหลดแล้ว
- ยังมีข้อมูลกู้คืนชั่วคราวในอุปกรณ์ระหว่างชำระเงิน เพื่อรองรับการปิดหน้า/กลับจากการชำระเงิน ไม่ใช่การบันทึกงานในบัญชี
- หลังใช้สิทธิ์หรือชำระสำเร็จ ระบบเริ่มดาวน์โหลด PNG ขนาดเดิม 2256×3072 px บนเดสก์ท็อป มือถือ/เบราว์เซอร์ที่ไม่ยอมบันทึกอัตโนมัติจะเปิดหน้าบันทึก/แชร์ สามารถกดใหม่ได้โดยไม่เสียสิทธิ์
- ภาพที่เคยชำระหรือใช้เครดิตสร้างแล้วคงสิทธิ์เดิม การชำระแพ็กเกจเก่าที่ค้างอยู่ยังยืนยันได้ตามข้อมูลแพ็กเกจเดิม

วิธีติดตั้ง — ต้องอัปเดต client และ server พร้อมกัน
1. สำรองโค้ดและฐานข้อมูลก่อนติดตั้ง
2. หยุด instance รุ่นเดิมทั้งหมดชั่วคราว เพื่อไม่ให้รุ่นเก่ายังรับบันทึกงาน/ซื้อแพ็กเกจระหว่างกำหนดทะเบียนสิทธิ์เดิม
3. แตก ZIP ที่รากโปรเจ็ก แทนที่ตามเส้นทางในรายการด้านล่าง ไม่ต้องแก้รูป/โมเดล/ไฟล์ assets
4. ใช้ environment เดิมที่มี DATABASE_URL และคีย์ชำระเงิน แล้วรัน:
   npm ci
   node scripts/initialize-download-policy.mjs
   npm run build
5. เมื่อ initialize และ build ผ่าน จึง restart server แล้วเปิดให้ใช้งาน ต้องหยุดหาก initialize ล้มเหลว ห้ามลบตารางเพื่อฝืนให้ผ่าน
6. ให้ผู้ใช้โหลดหน้าใหม่เพื่อไม่ให้ค้าง UI รุ่นเก่า

ตัว initialize เพิ่มตารางนโยบาย/ทะเบียนงาน/ข้อยกเว้นและบันทึกจุดเริ่มใช้นโยบายหนึ่งครั้ง ไม่ตัดยอดเครดิตและรันซ้ำได้ หากไม่ได้รันสคริปต์ ระบบมีการเริ่มนโยบายเมื่อเรียกใช้ครั้งแรก แต่ควรรันก่อนเปิดรับผู้ใช้เพื่อให้เวลาตัดสิทธิ์แน่นอน
ไม่มีการเปลี่ยน package.json หรือ package-lock.json และไม่ต้องติดตั้งแพ็กเกจทดสอบใน production
