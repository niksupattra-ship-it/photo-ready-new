# IDพร้อม Studio — ปรับป็อปอัพสร้างรูปสำเร็จ

อ้างอิงโปรเจ็กต์ล่าสุด `niksupattra-ship-it/photo-ready-new` commit `e7d259cfc086c1c3c69233ee09a9b729ee30ef52` วันที่ 23 ตุลาคม 2026 ชุดแก้เสื้อเดิมก่อนหน้านี้อยู่ในฐานนี้แล้ว และคงไว้ครบ

## รูปแบบใหม่

- หัวข้อ “สร้างรูปสำเร็จแล้ว” พร้อมเครื่องหมายสำเร็จ
- แสดง “ใช้ … เครดิต” และ “เหลือ … เครดิต” ในกรอบสองช่อง
- ข้อความ “หากออกจากหน้า IDพร้อม Studio งานที่ยังไม่บันทึกจะหายไป และเครดิตที่ใช้แล้วไม่สามารถเรียกคืนได้”
- ปุ่มซ้าย “บันทึกงาน” และขวา “แก้ไขรูปต่อ” วางคู่กันบนคอมพิวเตอร์ มือถือ และแท็บเล็ต
- ใช้โทนกรมท่า–เขียวมิ้นต์ของ Studio พร้อมขอบ โฟกัสคีย์บอร์ด และพื้นที่แตะอย่างน้อย 44px

สถานะกำลังบันทึก/บันทึกแล้ว/บันทึกไม่สำเร็จ/ครบ 3 งาน ยังคงแสดงตามจริง ถ้าบันทึกอัตโนมัติสำเร็จ ปุ่มซ้ายจะแสดง “บันทึกงานแล้ว” และปุ่มขวายังแก้ไขต่อได้ รูปทดลองยังใช้ปุ่มรับรูปไม่มีลายน้ำตามสิทธิ์เดิม

## ยอดเครดิตที่แสดง

พบว่าค่าเดิมอาจเป็นยอดก่อนใช้เครดิต เพราะการโหลดข้อมูลสิทธิ์ยังไม่เสร็จ จึงเพิ่มการอ่าน `/api/wallet/balance` แบบ read-only หนึ่งครั้งหลังยืนยันงานสำเร็จ จำกัดเวลา 8 วินาที แสดงยอดเมื่ออ่านและตรวจบัญชีแล้วเท่านั้น ระหว่างรอแสดง “กำลังตรวจสอบยอดคงเหลือ…” หากอ่านไม่ได้จะแจ้งตามจริง ไม่ใช้ยอดเก่าหรือสร้างยอด 0 และไม่ขวางรูป การบันทึก หรือการแก้ไขต่อ

เครดิตซื้อและเครดิตทดลองแสดงแยกตามประเภทงาน โหมดทดสอบส่วนตัวแสดงใช้ 0/ไม่จำกัด การเรียกรูปที่เคยสร้างไม่เพิ่มป็อปอัพหรือการใช้เครดิต การอ่านยอดนี้ไม่แก้ข้อมูลบัญชี สิทธิ์ การชำระเงิน หรือวิธีเพิ่ม/หัก/คืนเครดิต ไม่มีคำขอ AI เพิ่ม

## วิธีอัปเดต

ชุดนี้เป็นไฟล์แก้ไขเฉพาะส่วน แทนที่ runtime 4 ไฟล์ตามตำแหน่งเดิม:

- `src/main.jsx`
- `src/studio-editor.jsx`
- `src/process-result-notice.jsx`
- `src/process-result-notice.css`

จากนั้น build/deploy ตามขั้นตอนเดิม แล้วเปิดหน้าเว็บใหม่เพื่อโหลด bundle ใหม่ ไม่ต้องแก้ฐานข้อมูลหรือรีเซ็ตบัญชี

ไฟล์ `scripts/check-process-result-balance.mjs`, README/VERIFY และ `preview/` เป็นชุดตรวจ เอกสาร และภาพตัวอย่าง ไม่ใช่ runtime ตัวเลขเครดิตในภาพตัวอย่างเป็นข้อมูลทดสอบ

## การตรวจสอบ

- Build ผ่าน 117 modules ด้วย dependencies ตาม lock เดิม มีคำเตือนขนาด bundle เดิม
- ชุดตรวจข้อมูลเครดิตป็อปอัพใหม่ 9 กรณี: ยอดหลังงานสำเร็จ, ศูนย์จริง, ข้อมูลผิด/บัญชีเปลี่ยน, ทดลอง/ส่วนตัว/แคช, บันทึกขณะยอดค้าง และคำตอบของงานเก่า
- Chromium และ WebKit ผ่าน 15 จุดตรวจต่อเอนจิน รวมจอ 320×568, 390×844, 768×1024, 844×390 และเดสก์ท็อป ปุ่มคู่กัน ไม่ล้นจอ โฟกัส/Escape และสถานะบันทึก/ทดลอง/งานเต็ม
- ชุดตรวจเสื้อเดิม 15, เริ่มประมวลผล/เครดิต 12, หน้าดูเครดิต 7 และสิทธิ์ Studio ผ่าน
- เทียบ runtime กับฐานล่าสุด เปลี่ยนเฉพาะ 4 ไฟล์ข้างต้น ระบบ backend/ฐานข้อมูล/แพ็กเกจและ helper ประมวลภาพคงเดิม

รันตรวจข้อมูลด้วย `node scripts/check-process-result-balance.mjs`

ยังไม่ได้ deploy ขึ้นเว็บจริง ไม่มีการใช้บัญชีลูกค้า เรียก AI เสียเงิน หรือเขียนข้อมูลการเงิน การตรวจเบราว์เซอร์เป็นเอนจินในเครื่องทดสอบ ไม่ใช่มือถือหรือแท็บเล็ตจริง
